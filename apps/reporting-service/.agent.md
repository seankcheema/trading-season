## Common Development Tasks

### Task 1: Add New Performance Metric

1. Define calculation in `metrics_calculator.py`
2. Add to `PerformanceMetrics` dataclass
3. Create Spring Boot service method
4. Add REST API endpoint in controller
5. Create Angular component for visualization
6. Add to UI dashboard

**Example:**
```python
@staticmethod
def calculate_information_ratio(
    returns: pd.Series,
    benchmark_returns: pd.Series
) -> float:
    """Calculate Information Ratio."""
    active_returns = returns - benchmark_returns
    return (active_returns.mean() / active_returns.std()) * np.sqrt(252)
```

### Task 2: Create New Report Type

1. Create DTO in `apps/business-backend/src/main/java/com/neueda/leap/report/dto/`
2. Create service in `apps/business-backend/src/main/java/com/neueda/leap/report/service/`
3. Create repository query in `apps/business-backend/src/main/java/com/neueda/leap/report/repository/`
4. Add REST endpoint in controller
5. Create Angular service in `apps/reporting-ui/src/app/services/`

### Task 3: Implement Scheduled Job

1. Create job class extending `Job` interface (Quartz)
2. Implement `execute()` method
3. Register in `ReportingScheduler`
4. Configure cron expression in `application.properties`
5. Add logging and error handling
6. Write unit tests

**Example:**
```java
@Component
public class DailyMetricsAggregationJob implements Job {
    @Override
    public void execute(JobExecutionContext context) throws JobExecutionException {
        // Run daily aggregation
        reportingService.aggregateDailyMetrics(LocalDate.now());
    }
}
```

## Performance Optimization Tips

1. **Use Materialized Views** for pre-aggregated data
2. **Index on** `account_id`, `date_calculated`, `instrument_id`
3. **Partition tables** by month on date fields
4. **Cache frequently accessed** metrics (5-min TTL)
5. **Batch update** materialized views hourly
6. **Use pagination** for large result sets (50 rows/page)

## Common Issues & Solutions

### Issue: Slow metric calculations
**Solution:** Use vectorized NumPy/Pandas operations, avoid Python loops

### Issue: Reports missing recent trades
**Solution:** Verify ETL scheduled job ran, check database indexes

### Issue: Dashboard timeout on large accounts
**Solution:** Implement query pagination, add caching layer, use materialized views

### Issue: Materialized view outdated
**Solution:** Check refresh job status, verify cron schedule, check database logs

## Database Schema Considerations

### Key Tables
- `performance_metrics` — Daily performance snapshots
- `trade_analytics` — Trade-level analysis by instrument
- `risk_metrics` — Daily risk assessment
- `audit_trail` — Transaction audit log (insert-only)

### Indexes (Must Have)
```sql
CREATE INDEX idx_perf_metrics_account_date 
ON performance_metrics(account_id, date_calculated DESC);

CREATE INDEX idx_trade_analytics_account_inst 
ON trade_analytics(account_id, instrument_id, period_start DESC);
```

### Materialized Views
```sql
-- Pre-aggregated daily metrics
CREATE MATERIALIZED VIEW daily_metrics_summary AS
SELECT account_id, DATE(date_calculated) as date,
       AVG(total_return_percent) as avg_return,
       MAX(sharpe_ratio) as max_sharpe
FROM performance_metrics
GROUP BY account_id, DATE(date_calculated);
```
