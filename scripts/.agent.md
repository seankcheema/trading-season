## Common Tasks

### Create New Strategy

**File:** `backtesting/strategies/my_strategy.py`

```python
class MyStrategy:
    def __init__(self):
        self.name = "My Trading Strategy"
    
    def should_buy(self, price_data, index):
        """Return True if should buy at this point"""
        if index < 1:
            return False
        
        # Example: Buy when price increases
        return price_data[index]['close'] > price_data[index-1]['close']
    
    def should_sell(self, price_data, index):
        """Return True if should sell at this point"""
        if index < 1:
            return False
        
        # Example: Sell when price decreases
        return price_data[index]['close'] < price_data[index-1]['close']
```

### Add New Metric

**File:** `analytics/metrics.py`

```python
def calculate_win_rate(trades):
    """Calculate percentage of winning trades"""
    if not trades:
        return 0
    
    winning = sum(1 for t in trades if t['profit'] > 0)
    return (winning / len(trades)) * 100
```

### Add Tests

**File:** `backtesting/test_strategy.py`

```python
import pytest
from backtesting.runbacktest import Backtest
from backtesting.strategies.my_strategy import MyStrategy

def test_my_strategy():
    data = [
        {'date': '2024-01-01', 'close': 100},
        {'date': '2024-01-02', 'close': 105},  # Up
        {'date': '2024-01-03', 'close': 102},  # Down
    ]
    
    backtest = Backtest(MyStrategy(), data, initial_balance=10000)
    results = backtest.run()
    
    assert results['final_balance'] > 0
    assert len(results['trades']) > 0
```

## Common Issues & Fixes

| Issue | Cause | Fix |
|-------|-------|-----|
| `ModuleNotFoundError` | Dependencies not installed | `pip install -r requirements.txt` |
| `FileNotFoundError` | Data file missing | Check file path & location |
